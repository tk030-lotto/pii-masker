# 個人情報マスキングツール（pii-masker）

画像に写った氏名・電話番号・住所などを、ブラウザ内で黒く塗って隠せるローカル完結型のWebツールです。

## こんなときに

書類や会員証、名刺の写真を、人に見せたり送ったりしたいとき。でも、氏名や住所、電話番号は見せたくない。SNS に上げる前に、写り込んだ個人情報だけを消したい。そういうときに役立ちます。画像編集ソフトを開かなくても、ブラウザだけで済ませられます。

## 主な機能

- **ブラウザ内処理（外部通信 0件）**: 画像は外部サーバーへ送信されず、お使いのブラウザ内部だけで処理されます。
- **ドラッグで黒塗り**: 隠したい場所をドラッグするだけで、黒い矩形を作れます。
- **元に戻す／やり直し**: 塗りすぎても「元に戻す」で何度でもやり直せます。
- **仕上がり確認**: 保存の前に、塗った結果を確認できます。
- **PNG で保存**: できあがった画像は PNG で保存できます。
- **大きい画像の縮小**: 約1,600万画素を超える画像は、自動で縮小して処理します。

## 使い方

### ブラウザで使う（かんたん）
1. [ツールを開く](https://zero-dev.jp/pii-masker/) をクリックします。
2. 「画像を選択」を押して画像を選びます。または、点線の枠の中に画像をドラッグ＆ドロップします。
3. 画像を選ぶと、編集画面に切り替わります。画像と「矩形: 0件」の表示が出ます。
4. 隠したい場所を、ドラッグして黒い矩形で塗ります。塗ると「矩形: 1件」のように件数が増えます。
5. 必要なら、「元に戻す」「やり直し」で調整します。
6. 「仕上がり確認」を押すと、塗った結果が表示されます。
7. 「マスキング画像を保存」を押すと、PNG ファイルがダウンロードされます。

### ダウンロードして使う（パソコンに保存する場合）
1. このリポジトリのファイルをダウンロードし、ZIPファイルを展開します。
2. 展開したフォルダ内の `index.html` をブラウザで開きます。
3. あとは「ブラウザで使う」と同じ手順で操作できます（オフライン環境でも動作します）。

## うまくいかないとき
- **「非対応のファイル形式です」と出る**: 使えるのは JPEG（.jpg / .jpeg）、PNG（.png）、WebP（.webp）です。
- **塗ったはずの場所が見えてしまう**: 保存の前に「仕上がり確認」で確かめてください。塗り直すか、矩形を大きくしてください。
- **画像が粗く保存される**: 約1,600万画素を超える画像は縮小しています。解像度の高い元画像で試してください。

## 動作環境
モダンブラウザ（Google Chrome、Microsoft Edge、Firefox、Safari の現行版）。JavaScript と Canvas が有効になっていること。

## 制限・注意
- 文字を自動で見つけて塗る機能は、まだありません。いまは手で塗ってください。
- 対応している画像は JPEG・PNG・WebP です（1枚ずつ処理します）。
- 約1,600万画素を超える画像は、縮小して処理します。
- 塗り残しがないかは、保存した画像をご自身で最終確認してください。
- 写真の GPS 情報を消すことを主目的にしたツールではありません（出力画像に Exif などのメタデータは保持しません）。

## 外部通信
外部への通信は行いません（外部通信 0件）。画像の読み込みから保存まで、すべて端末のブラウザ内で処理します。外部への通信は、Content Security Policy（CSP）で技術的に禁止しています。

## 開発者向け

- **構成**: `index.html` / `css/style.css` / `js/`（`app.js`, `history.js`, `image.js`, `masker.js`, `ui.js`）
- **技術**: 素の JavaScript と Canvas・File API・Blob。外部ライブラリは使っていません。
- **データの流れ**: 画像を File API で読み込み → Canvas に描画 → 黒塗りを合成 → Blob にしてダウンロード。外部への送信はありません。
- **セキュリティ**: CSP（`default-src 'self'`）で通信を制限。画面への出力は `textContent` を使い、`innerHTML` は使いません。
