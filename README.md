# 個人情報自動マスキングツール

画像内に写り込んだ**顔・電話番号・メールアドレス・カード番号などの個人情報を、ブラウザ上でマスキングするローカル完結型Webツール**です。

画像を外部サーバーへアップロードせず、端末のブラウザ内で処理します。

自動検出は「候補の提示」までです。**何を塗るかの最終判断は、利用者が行います。**

## 検出できるもの・できないもの

### 自動で候補にするもの（v0.2以降）

- 電話番号
- メールアドレス
- 郵便番号
- カード番号
- 口座番号（「口座番号」「普通」などのラベルが近くにある場合のみ）
- 顔（v0.3以降）

### 自動では検出しないもの（手動で塗ってください）

- 氏名
- 住所
- 日付、位置情報（GPS）などの文字
- 手書き文字、縦書き文字、斜めの文字、極端に小さい文字
- ナンバープレート
- QRコード・バーコード
- SNSのアイコン・表示名・アカウントID
- 地図

**特に、チャットやSNSのスクリーンショットでは、表示名やアイコンが個人情報になりやすいため、手動で塗ってください。**

## 利用イメージ

### v0.1

```text
画像を選択
   ↓
塗りたい場所を矩形で指定
   ↓
仕上がりを確認
   ↓
マスキング済み画像を保存
```

### v0.2以降

```text
画像を選択
   ↓
「候補を検出」を押す
   ↓
個人情報の候補が表示される
   ↓
利用者が確認（採用・解除・手動で追加）
   ↓
仕上がりを確認
   ↓
マスキング済み画像を保存
```

画像を読み込んだだけでは、解析は始まりません。解析の前に、読み込むデータの大きさが表示されます。

## PrivacyPhotoとの違い

本ツールと、既存の **PrivacyPhoto: GPS & Exif Data Cleaner** は目的が近いように見えますが、処理対象が異なります。

### PrivacyPhoto

画像ファイルに保存されているExif等のメタデータを除去します。

- GPS位置情報
- 撮影日時
- カメラ・端末情報
- Orientationなど

### 個人情報自動マスキングツール

画像そのものに表示されている情報を隠します。

- 顔
- 電話番号
- メールアドレス
- カード番号
- その他、手動で指定した領域

つまり、

> **PrivacyPhoto = 画像ファイルの裏側にある情報を除去**

> **本ツール = 画像に見えている情報を隠す**

という役割分担です。

**本ツールで保存した画像は、Exif等のメタデータが保持されません。** ただし、メタデータの除去を目的とする場合は、PrivacyPhotoを使ってください。

## プライバシー

画像処理はローカルブラウザ内で行います。

- 元画像を外部サーバーへアップロードしません
- OCR結果を外部送信しません
- 顔画像をサーバーへ送信しません
- クラウドへの画像保存を行いません
- 元画像を上書きしません
- 画像・OCR結果・個人情報を、ブラウザに保存しません

外部への通信は、技術的にも禁止しています（Content Security Policy）。ブラウザの開発者ツールの「Network」タブで、画像を読み込んでから保存するまで、通信が発生しないことを確認できます。

重要な画像を扱う場合は、処理後の出力画像についても、利用者自身で最終確認してください。

## 動作環境

- PC・スマートフォンの現行ブラウザ（Chrome / Edge / Firefox / Safari）
- JavaScript と Canvas が有効になっていること
- 画像の処理は端末内で行うため、サーバーへの接続は不要

## 外部通信

このツールは、外部と通信しません。画像の読み込みから保存まで、すべて端末のブラウザ内で処理します。外部への通信は、Content Security Policy（CSP）で技術的に禁止しています。

## 制限・注意

自動検出には限界があります。

- 誤検出する場合があります。
- 個人情報を検出できない場合があります。
- 複雑な背景や小さな文字では認識精度が低下する場合があります。
- マスキング後も画像全体を確認してください。

本ツールは、個人情報の漏洩を防げることを保証しません。画像共有前の確認・マスキングを支援するためのツールです。

## 対応画像形式

初期対応：

- JPEG / JPG
- PNG
- WebP

HEIC / HEIFなどの追加形式は将来拡張候補とします。

約1,600万画素を超える画像（高画素のスマートフォンの写真など）は、縮小して処理します（縮小した場合は画面に表示されます）。上限以下の画像は、元の大きさのまま保存します。

## 基本的な使い方

### 1. 画像を選択

「画像を選択」から画像を読み込みます。パソコンでは、画像をドロップエリアへドラッグ＆ドロップすることもできます。

### 2. 塗る場所を指定

「描画・編集」モードで、塗りたい場所をなぞって矩形を作ります。矩形は、動かしたり、大きさを変えたり、削除（「削除」または「全消去」）したりできます。間違えたときは「元に戻す」を使います。

画面の拡大や移動をしたいときは、「表示・移動」モードに切り替えます（2本指でも拡大・縮小・移動できます）。

### 3. 候補を検出（v0.2以降）

「候補を検出」を押すと、電話番号などの候補が矩形で表示されます。

不要な候補は解除し、見落とした情報は手動で追加します。確度の低い候補は、最初は採用されていません。

### 4. 仕上がりを確認

「仕上がり確認」で、塗りを反映した画像を確認します。塗りは、指定した矩形より少し広く入ります。文字の端が残っていないか、塗り忘れがないかを見てください。

### 5. 保存

元画像とは別のファイルとして、マスキング済み画像を保存します。原則として入力と同じ形式で、元の大きさのまま保存されます（画素数の上限を超えた画像は、縮小後の大きさです）。ブラウザによっては、入力と同じ形式で書き出せない場合があり、そのときは実際の形式で保存し、画面に表示します。

例：

```text
sample.jpg
↓
sample_masked.jpg
```

## 公開

静的Webアプリとして構築し、GitHub Pages等で公開できる構成を基本とします。サブパス公開でも動作するよう、参照はすべて相対パスにしています。

サーバー側で画像処理を行わないため、一般的なWebサービスとは異なり、画像を保管するバックエンドを必要としません。

## セキュリティ方針

本ツールでは、個人情報そのものを収集する設計を採用しません。

特に以下を、ブラウザに保存しないことを原則とします。

- 元画像
- OCR全文
- 個人情報文字列
- 顔画像
- マスキング前の画像データ

## 今後の拡張候補

中核目的を「画像内個人情報の検出・マスキング」に限定したまま、実際の利用で必要と分かったものから検討します。

- 住所・氏名の候補検出
- マイナンバー（12桁）の候補検出
- QRコード・バーコードの検出
- SNSのアカウントIDの候補検出
- モザイク・ぼかしなど、マスキング方式の選択
- 複数画像一括処理、ZIP一括出力
- HEIC / HEIF対応
- 出力画像の再チェック機能
- PWA化、オフライン利用
